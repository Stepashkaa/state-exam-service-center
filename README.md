# State Exam Service Center

Веб-приложение для подготовки к государственному экзамену.

Проект реализует SPA-архитектуру:

- frontend: React + JavaScript + Vite + Bootstrap;
- backend: Java + Spring Boot + Maven + PostgreSQL + Spring Data JPA.

## Структура проекта

- `frontend` — клиентская часть приложения;
- `service-center-backend` — серверная часть приложения.
